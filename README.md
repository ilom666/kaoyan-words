# 刷单词 Web 应用

基于《考研英语你还在背单词吗？》词库的本地刷词应用。

## 项目描述

此项目词库非官方整理，目前使用OCR识别，存在一定单词的错误，目前整理到lesson14，因为作者目前只学到了14，后续按顺序学，学到哪补充到哪，感兴趣的也可自行跟哔哩哔哩27版考研英语你还在背单词吗课程学习并自行补充，每个章节只有几个单词不对，如有需要联系方式QQ3545996137。

## 项目结构

```text
words/
├── app/                  前端（原生 HTML/CSS/JS，无构建步骤）
│   ├── index.html        页面结构与各视图容器
│   ├── style.css         全部样式（含划词气泡、逐段对照）
│   ├── app.js            主程序：词库、学习进度、视图切换、发音、依赖注入
│   ├── games.js          小游戏模块：快问快答 / 听音辨词，仅暴露 WordGames
│   └── reading.js        AI 阅读理解模块：生成、划词翻译、保存，仅暴露 WordReading
├── data/
│   ├── words.json        词库种子：首次启动导入 SQLite，之后不再写入；提交此文件即提交词库更新
│   └── app.db            SQLite 运行时库（词库 + 进度 + 设置 + 游戏记录 + 文章），自动生成、不入库
├── docs/
│   ├── DEEPSEEK.md       DeepSeek API 接入说明（申请、配置、调用链、排错）
│   ├── EXCEL.md          Excel 模板表头、字段格式与导入规则
│   └── YOUDAO.md         有道词典接入说明
├── server.py             零依赖 Python 标准库服务：静态文件 + 词库增删改 + 有道/DeepSeek 代理
├── start.command/.bat/.sh   macOS / Windows / Linux 一键启动脚本
└── .gitignore            排除原书 PDF、OCR 脚本、备份与运行时文件
```

模块之间通过依赖注入协作：`app.js` 只把 `esc / toast / speak / getWords / getKnown / fetchYoudao / openGame / openReading` 等能力传给 `games.js`、`reading.js`，两个子模块互不读写对方内部变量。

## 启动

服务端仅用 **Python 标准库**，无需 `pip install` 任何依赖；启动后用浏览器打开 http://localhost:8765 。

| 系统 | 双击启动 | 命令行启动 |
|---|---|---|
| macOS | `start.command` | `python3 server.py` |
| Windows | `start.bat` | `python server.py` |
| Linux | `start.sh` | `python3 server.py` |

> **跨电脑运行说明（零预装）**：`server.py` 是纯 Python 3 代码，拷走整个文件夹即可在任何电脑运行。三个 `start.*` 脚本已经把下载安装写进去了——**双击时若检测到系统没有 Python，会自动下载官方 Python 3 安装包并静默安装，然后启动服务**（macOS 下载 python.org 的 `.pkg` 需输入开机密码；Windows 下载 `.exe` 静默装到当前用户目录，无需管理员；Linux 按发行版调用 `apt`/`dnf`/`yum` 等，需 sudo）。安装只需一次，之后直接启动。若自动安装失败（如无网络），脚本会提示手动安装地址，也可直接用命令行启动。默认端口 8765，可用 `python3 server.py 9999` 更换（`start.*` 固定为 8765）。

## 功能

- **选课刷词**：按 Part 1 核心词 / Part 2 基础词 / Part 3 扩展词分类，选中 Part 后显示对应 Lesson（Part 3 按字母段分组）；网格上方提供「随机顺序」「只刷不认识的」，**选中一个或多个课程后按 Enter 即可开始刷词**
- **列表复习**：不认识 / 已收藏列表支持词义遮挡（逐条点击才显示，可一键全部显示/关闭遮挡）、按 Unit 分组、每页条数与完整翻页；列表内按 Enter 可直接开始刷这些词
- **三段式卡片**：
  1. 单词 + 标准 IPA 音标（可点击朗读，E 键）
  2. 词义（默认遮罩，点击显示）
  3. 谐音记忆 + 例句（默认遮罩）
- **发音**：有道在线高清发音，**默认英音（英式 IPA 音标）**，可切换美音 / 系统语音，音标显示随之切换；旧设置会自动迁移一次，之后尊重手动选择
- **有道自动补全**（`GET /api/youdao?q=` 服务端代理，避开 CORS）：新增/编辑词条只填单词即可自动补美音、英音、中文释义（**只补空字段，不覆盖已填内容**）；编辑弹窗内有「🔄 有道补全」手动按钮，接入说明见 [docs/YOUDAO.md](docs/YOUDAO.md)
- **遮罩模式**：遮词义+记忆（点击一起显示）/ 分段遮罩 / 只遮记忆例句 / 全部显示 / 遮单词（看意思回忆）
- **认识 / 不认识** 标记，生词可重复刷；自动朗读、标记后自动下一词
- **收藏**：刷词页右上角「☆ 收藏」（快捷键 S），收藏状态独立保存
- **刷词即时修改**：点击卡片上方的 Lesson / 编组徽标（或按 Q）打开「快速修改」，可当场改单词、音标、词义、徽标上的编组名以及 Part / Unit / Lesson；保存即写入词库并即时刷新卡片。面板层级高于顶栏且顶部留安全间距，不会被 `topbar` 遮挡；底部「✏️ 完整编辑」可跳转到全部字段编辑
- **专项列表**：首页/统计页的「不认识」「已收藏」统计卡可点击进入列表，支持搜索、朗读、取消收藏/标为认识、分页；列表顶部一键「刷不认识的单词 / 刷已收藏的单词」，退出后返回列表
- **词库管理**：搜索、编辑（单词/音标/词义/记忆/例句/派生词等全部字段）、新增、删除；单击选中后点「新增」或**双击任意行**会在该词后方插入新词；开启「⇅ 交换位置」后依次点击两行（支持跨页）即可交换顺序，用于修正 OCR 错序，交换会写回词库并影响刷词顺序
- **固定工具栏**：词库管理与单词列表的搜索/操作栏在向下滚动时保持显示，紧贴顶栏下方（高度按实际顶栏动态计算）
- **小游戏**（顶栏「小游戏」，从**已学过的单词**中出题，边玩边记）：
  - **快问快答**：看中文选英文 / 看英文选中文，限时四选一，答对按「剩余时间 + 连击」加分、答错扣分；题数与每题限时均可自行填写（默认 10 题 × 10 秒），也提供常用值快捷按钮
  - **听音辨词**：播放发音选出听到的单词，可「再听一遍」（复用有道发音）；题数与限时同样可自定义
  - 本局结束如有答错，标题会显示「本局结束，你个菜🐶」；全对则显示「本局结束」并给出全对提示
  - **AI 阅读理解**：小游戏里的独立模块（`app/reading.js`，依赖注入、与主程序低耦合）。接入 DeepSeek，把已学单词（最多 300 个）交给 AI，生成英文短文、逐段对照翻译和 3~5 道理解题；可填主题、选长度、在线作答看解析。阅读时用鼠标拖动选中单词，会在其左/右侧连线显示翻译（优先本地词库，缺失时查有道）；文章自动保存到本机，配置见下方「AI 阅读理解配置（DeepSeek）」
  - 出题范围可选「全部已学 / 只刷不认识 / 已收藏」；结算显示得分、正确率、最高连击与错题回顾（可点🔊朗读），最高分按模式+范围存本地
  - 键盘 `1`~`4` 快速作答、`E` 朗读、`Esc` 退出；游戏模块 `app/games.js` 通过依赖注入复用主程序的词库/进度/发音，与主逻辑低耦合
- **统计**：总览与每课认识率
- **数据存储（SQLite）**：词库与所有应用状态统一存 `data/app.db`（由标准库 `sqlite3` 读写，零依赖）；`data/words.json` 只作首次导入种子。`words` 表为**结构化列**（每个字段一列，`hints`/`derivatives`/`phrases`/`notes`/`related` 五个数组字段以 JSON 文本列保存），支持按字段 SQL 查询与单条 `UPDATE/INSERT/DELETE`，插入/交换位置/编辑均走单条 SQL，不再全表重写。学习进度、收藏、设置、选中课程、小游戏最高分、阅读文章也在 SQLite，不再用浏览器 localStorage；**唯一例外是 DeepSeek API Key**，仅暂存浏览器本地。JSON / Excel 导出导入仍可用
- **Excel 导入导出**：顶栏「导出Excel」把词库导出为 `.xlsx`，「Excel模板」下载带示例的模板，「导入Excel」把编辑好的表写回词库；表头、字段格式与导入规则见 [docs/EXCEL.md](docs/EXCEL.md)。JSON 导出仍保留，且会额外带上学习进度/收藏

## AI 阅读理解配置（DeepSeek）

小游戏 → 选「🤖 AI 阅读理解」→ 填主题（可留空）、选文章长度与题目数量 → 点「✨ 生成阅读」。生成结果包含英文短文、逐段对照翻译、文中用到的已学单词和阅读理解题，可在线作答看解析。

- **划词翻译**：用鼠标拖动选中文章中的单词，会在靠近选中位置的左/右侧弹出翻译并用短线连接（选中词在屏幕左半时气泡放右侧，反之放左侧，避免遮挡）。**优先查本地词库，命中时还会显示该词所在的「第X单元 · 第Y课」，缺失时再走有道**；点页面其他位置或按 `Esc` 关闭气泡
- **逐段对照**：每段英文下的中文翻译默认隐藏，点「显示翻译」才展开该段；题目中文翻译也一样，方便先自测再对照
- **自动保存**：生成的文章自动存到 SQLite（最多 50 篇），答题记录同步保存；菜单或结果页点「📚 已保存文章」可查看、继续做题或删除
- **返回**：阅读各页面都有「🎮 返回小游戏」按钮；在刷词进行中切到其他菜单后，点顶栏「📖 刷单词」或「选课」会回到刚才的刷词进度，而不是选课页

**接入 DeepSeek 只需两步**：在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请 API Key，然后二选一配置——① 启动服务前设置环境变量 `DEEPSEEK_API_KEY`（推荐）；② 在菜单「DeepSeek API Key」处填写（可勾选记住到本机浏览器）。Key 只在本机服务端进程内使用，不写入仓库。完整步骤、可选环境变量、调用链与排错见 [docs/DEEPSEEK.md](docs/DEEPSEEK.md)。

## 词库来源

词库数据由《考研英语你还在背单词吗？》电子PDF扫描版经本地 OCR 识别与结构化整理得到，本仓库以 `data/words.json` 作为结构化词库种子（运行时导入 SQLite）；原书 PDF 与 OCR 提取脚本未随仓库发布。

音标统一为有道词典标准 IPA（美音 `phonetic`，英音 `phonetic_uk`），切换「发音」设置时卡片音标自动切换。由于原书为扫描件，个别词条的词义/例句可能存在串栏粘连或识别错误（部分词条已标「待校对」），可在「词库管理」或刷词卡片右上角 ✏️ 中直接修正。
