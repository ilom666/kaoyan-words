# 有道词典接入说明

应用的有道能力用于两件事：**在线发音**（高清音频）与**音标/释义补齐**（新增或编辑词条时自动填充空字段）。全部基于有道公开接口，无需账号、无需 API Key、无费用。

## 一、接口清单

| 用途 | 接口 | 说明 |
|---|---|---|
| 查音标 / 释义 | `https://dict.youdao.com/jsonapi?q=<单词>` | 返回 JSON，由服务端解析 |
| 在线发音 | `https://dict.youdao.com/dictvoice?type=<1或2>&audio=<单词>` | `type=1` 英音，`type=2` 美音；浏览器直接播放 |

> 查询接口在浏览器里直连会被 CORS 拦截，因此统一走本机服务端代理 `GET /api/youdao?q=`。发音接口不受 CORS 限制，前端直接播放。

## 二、返回结构与解析规则

`jsonapi` 返回的 JSON 中，词条数据出现在 `ec.word[0]` 或 `simple.word[0]`（两处结构相同，依次尝试）：

```json
{
  "ec": { "word": [ {
    "usphone": "ˈæpl",
    "ukphone": "ˈɑːpl",
    "trs": [ { "pos": "n.", "tran": "苹果" } ]
  } ] }
}
```

解析实现位于 `server.py` 的 `youdao_lookup(word)`：

1. 依次读取 `ec`、`simple` 下的 `word[0]`；
2. `usphone` → 美音，`ukphone` → 英音，统一补成 `/.../` 格式；
3. 释义来源两处：`trs[].tran`（配合 `pos` 词性）与 `trs[].tr[].l.i`（字符串或字符串数组）；
4. 清洗：删除 `【名】` 及其后内容、去掉首尾中英文标点与空格、合并连续空白、最多保留 220 字；
5. 返回 `{ ok, word, us, uk, meaning }`，其中 `ok` 表示三项里至少有一项有效。

## 三、三层调用链

### 1. 服务端代理（`server.py`）

- `youdao_lookup(word)`：唯一的解析实现，供代理接口与批量脚本**共用同一份逻辑**；
- `GET /api/youdao?q=<单词>`：调用上述函数并返回 JSON；
- 请求带 `User-Agent: Mozilla/5.0`，超时 8 秒；异常返回 `{ok:false, error}`。

### 2. 前端浏览器（`app/app.js`）

- `fetchYoudao(word)`：`fetch('/api/youdao?q=...')`，失败返回 `null`；
- `autoFillEmpty(patch)`：保存词条时自动调用，**只填空字段**——`phonetic`（美音）、`phonetic_uk`（英音）、`meaning`；三者都已填则直接跳过，不发起请求；
- 触发点：刷词页「快速修改」保存、词库管理「完整编辑」保存；
- 手动按钮：编辑弹窗内的「🔄 有道补全」，只把当前为空的字段填入，**再点保存才生效**；
- 发音：`speak()` 直接播放 `dictvoice`，按设置选英音(`type=1`)或美音(`type=2`)，不经代理、不消耗查询接口。

### 3. 批量同步（本地工具，未随本仓库发布）

批量补齐与质量排查脚本仅在本机使用，未包含在本开源仓库中。前端「有道补全」按钮与保存时的自动补齐已覆盖日常增量补齐需求，可疑词头可在「词库管理」中逐条核对修正。

## 四、关键设计原则

- **只补空、不覆盖**：用户手动录入或修改的内容优先级最高，前端与脚本都绝不覆盖；
- **服务端代理**：规避浏览器 CORS，并统一解析逻辑，避免前后端规则漂移；
- **英音优先**：默认 `settings.accent='uk'`，卡片显示 `phonetic_uk`；切换美音时显示 `phonetic`；
- **离线可用**：词库音标与释义已全部补齐，只有「自动补全 / 在线发音」需要网络；离线时这些功能静默降级，不影响刷词。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 查询返回 `ok:false` | 单词拼写可能有误，或为生僻词 / 屈折形式；在编辑弹窗人工填写并核对 |
| 发音无声 | 确认网络可用；`dictvoice` 需联网 |
| 补全接口报连接错误 | 确认 `server.py` 已启动、端口为 8765 |
| 换端口后补全失效 | 修改 `app/app.js` 中接口地址，与 `server.py` 启动端口保持一致 |
| 想排查词库质量 | 在「词库管理」中逐条核对可疑词头并修正 |
