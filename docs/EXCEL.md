# Excel 模板与导入导出说明

词库可以用 Excel（或 WPS）直接编辑后导回应用，全程无需安装 Python 依赖：导出与解析都在本机 `server.py` 中用标准库完成，生成的就是标准 `.xlsx` 文件。

## 一、入口

顶栏右侧三个按钮：

| 按钮 | 作用 |
|---|---|
| **导出Excel** | 把当前全部词库导出为 `words_日期.xlsx`，第一行为固定表头 |
| **Excel模板** | 下载只含表头 + 一行示例的 `words_template.xlsx`，用于从零整理 |
| **导入Excel** | 选择编辑好的 `.xlsx`，写回词库并提示「更新 / 新增 / 跳过」条数 |

> JSON 的「导出 / 导入」按钮仍然保留；JSON 备份还包含学习进度与收藏，Excel 只处理词库本身。

## 二、模板表头（共 22 列，顺序固定）

| 列 | 表头 | 对应字段 | 说明 |
|---|---|---|---|
| A | ID | `id` | 词条唯一编号；匹配更新时优先用此项 |
| B | 单词 | `word` | **必填**；整行为空则跳过 |
| C | 美音音标 | `phonetic` | 文本，如 `/əˈmɪʃən/` |
| D | 英音音标 | `phonetic_uk` | 文本 |
| E | 释义 | `meaning` | 文本 |
| F | 记忆提示 | `hints` | 格式见下文「特殊字段」 |
| G | 英文例句 | `example_en` | 文本 |
| H | 中文例句 | `example_zh` | 文本 |
| I | 派生词 | `derivatives` | 多个用 `；` 分隔 |
| J | 同义词 | `synonyms` | 文本 |
| K | 短语 | `phrases` | 多个用 `；` 分隔 |
| L | 形近对比 | `compare` | 文本 |
| M | 备注 | `notes` | 多个用 `；` 分隔 |
| N | 编号 | `no` | 文本，如 `001` |
| O | 分组 | `group` | 文本 |
| P | 相关词 | `related` | 多个用 `；` 分隔 |
| Q | 页码 | `page` | 数字 |
| R | Unit | `unit` | 数字 |
| S | Lesson | `lesson` | 数字 |
| T | Part | `part` | 数字 |
| U | Part标题 | `part_title` | 文本 |
| V | 疑似标记 | `suspect` | 文本 |

## 三、特殊字段格式

- **记忆提示（F 列）**：每条写成 `类型：内容`，多条用 `；` 分隔，例如
  `谐音：发音类似“飞蛾死”；联想：re(反复)+bel`。可识别的类型为 `谐音 / 联想 / 词根词缀 / 形近对照 / 记忆 / 助记`；不带类型前缀的内容统一记为「记忆」。
- **数组字段（I/K/M/P 列）**：多项之间用 `；`（中文分号）分隔；也可使用英文 `;` 或换行。
- **数字字段（Q~T 列）**：填整数；留空表示不修改。
- **空单元格的含义**：**留空 = 保持原值，不覆盖**。想清空某字段请填入一个空格后再导入。

## 四、导入匹配规则

按行依次处理（跳过第 1 行表头）：

1. **匹配目标**：
   - 若填了 `ID` 且词库中存在该 ID → 更新该词条；
   - 否则按 `单词` 精确匹配（忽略大小写）→ 更新该词条；
   - 两者都找不到 → 新增词条，自动分配新 ID。
2. **覆盖方式**：只覆盖非空单元格对应的字段，其余保持原值；`单词` 列为空的整行会被跳过。
3. **安全性**：导入会先由服务端把当前词库备份到 `data/words.backup.json`（不入库），导入异常不会损坏原数据。批量修改前建议先点一次「导出」留底。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示「表头缺少『单词』列」 | 请用「导出Excel」或「Excel模板」生成的表，不要改动第 1 行表头 |
| 导入后某些字段没变 | 对应单元格留空了；留空表示保持原值，需填入新内容 |
| 想批量删除词条 | Excel 导入不支持删除；请在「词库管理」中删除，或用 JSON 导入 |
| Excel 打开乱码 | 本工具生成的是 UTF-8 编码的 `.xlsx`，正常不会乱码；请勿另存为 CSV |
| 只想改几列 | 只填要改的列，其余留空即可；ID 列建议保留以便精确匹配 |
